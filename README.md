# Libreoffice-Make-it-Fit
adds Wordperfect style "Make it fit" feature that will automatically adjusts spacing , margins, etc, to fit on a given number of pages.

Sometimes you need a document to fit on 5 pages. Wordperfect had this feature, this is adding it back to current workflows

This feature has 3 options
1) strict Make it fit-- will adjust typesetting within printable area to make a document fit on a given number of pages. Will fail if the task is impossible (eg 20 pages cannot fit on 5. 7 or 6 can fit on on 5...)
2)Make it fit Chicago style-- reformats to fit on a given number of pages but keeps Chicago style margins and spacing
3)Make it fit APA-- as above,  APA style

note: There is no MLA style because MLA is clunky, unwieldily, and inefficient. If it worked, it would be Chicago.


As an added bonus, this extension adds an easy "Suppress numbering on page 1" feature -- to prevent page numbers being on title pages and will instantly make page 1 ... page 2 of the document (but really the first page of content) this is a feature wordperfect perfected and the MS Word made difficult and I cannot figure out how to do it in libreoffice at all and that is unacceptable.
